# Car Finder

A mobile app that remembers where you parked — tracks your phone's speed and
location in the background, detects when you've parked, and shows you the
direction and distance back when you return.

The project itself, including the full write-up of what it does and how it
was built, lives in [`CarFinder_MVP/`](./CarFinder_MVP/README.md).

`_rerun_impl_stash/` holds two earlier implementation attempts at the same
feature, kept for comparison — see the README above for why.
